MANAGER MAC — BẢN macOS
=======================

CHỌN ĐÚNG FILE
  - Mac chip Apple (M1, M2, M3, M4…): ManagerMac-<phiên bản>-macos-arm64.zip
  - Mac chip Intel:                   ManagerMac-<phiên bản>-macos-x64.zip
  (Xem ở  > Giới thiệu về máy Mac này > Chip / Bộ xử lý.) Cần macOS 14 Sonoma trở lên.

CÀI ĐẶT
  1. Giải nén, kéo ManagerMac.app vào thư mục Applications (Ứng dụng).
  2. Lần đầu mở: app chưa có chữ ký Apple Developer nên macOS sẽ chặn ("không thể mở vì không xác minh được nhà phát triển").
     Cách mở:
       - Vào System Settings (Cài đặt hệ thống) > Privacy & Security (Quyền riêng tư & bảo mật),
         kéo xuống, bấm "Open Anyway" (Vẫn mở) cạnh dòng nói về ManagerMac, rồi xác nhận.
       - Hoặc mở Terminal và chạy:   xattr -dr com.apple.quarantine /Applications/ManagerMac.app
  3. Biểu tượng Manager Mac nằm trên thanh menu (góc phải trên) và trong Dock.
     Bấm nút đóng (đỏ) chỉ ẩn cửa sổ; muốn thoát hẳn chọn "Thoát" ở biểu tượng trên thanh menu.

TÍNH NĂNG (bản đầu tiên)
  - Tổng quan: dung lượng ổ đĩa, RAM, tổng đã dọn.
  - Dọn rác: cache Xcode/Simulator, cache Homebrew/npm/pip/Yarn, cache trình duyệt, log cũ; ~/Library/Caches và Thùng rác
    phải "Xem file" trước khi dọn. File bị xoá chuyển vào Thùng rác của macOS nếu luật đặt như vậy.
  - Gợi ý dọn file: file lâu không sửa, file lớn, bộ cài cũ (.dmg, .pkg…) trong Downloads, file trùng. Chỉ gợi ý.
  - Tiến trình: app nào chiếm CPU/RAM (gộp các tiến trình "Helper" vào app chính), end task, khởi động lại app,
    "Giải phóng RAM" (lệnh purge của macOS, hỏi mật khẩu quản trị).
  - Cài đặt: ngôn ngữ, sáng/tối (theo macOS), tự chạy khi đăng nhập.

QUYỀN macOS CÓ THỂ HỎI
  - "Manager Mac muốn điều khiển <app>": khi bấm Khởi động lại một app (để thoát app như Cmd+Q). Chọn OK.
  - Mật khẩu quản trị: khi bấm Giải phóng RAM (lệnh purge).
  - Một số thư mục được bảo vệ (Mail, Safari…) không quét được nếu chưa cấp "Full Disk Access"; app không cần quyền này
    cho các tính năng chính.

DỮ LIỆU
  Cấu hình, lịch sử dọn: ~/Library/Application Support/ManagerMac
  Log: ~/Library/Logs/ManagerMac
  Tự chạy khi đăng nhập: ~/Library/LaunchAgents/vn.quangns.managermac.plist (bật/tắt trong Cài đặt).

GỠ CÀI ĐẶT
  Tắt "Tự chạy khi đăng nhập" trong Cài đặt, thoát app, kéo ManagerMac.app vào Thùng rác.
  Xoá thêm ~/Library/Application Support/ManagerMac nếu muốn xoá dữ liệu.


MANAGER MAC — macOS EDITION
===========================
  - Apple silicon (M1–M4): use the arm64 zip; Intel Macs: the x64 zip. Requires macOS 14 Sonoma or later.
  - Unzip, drag ManagerMac.app to Applications. The app is not signed with an Apple Developer ID, so the first time:
    System Settings > Privacy & Security > "Open Anyway", or run in Terminal:
      xattr -dr com.apple.quarantine /Applications/ManagerMac.app
  - The icon lives in the menu bar and Dock; the red close button only hides the window.
  - macOS may ask to let Manager Mac control an app (Restart) and for an admin password (Free memory / purge).
